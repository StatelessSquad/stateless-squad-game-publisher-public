# StateLess Squad

StateLess Squad makes small, bright games for phones and the web: a kids' word garden, a tower of light, a vibecoder's endless runner, a merge puzzle and more. No ads, no accounts, no tracking, and they all play offline.

Live at https://www.statelesssquad.com/

This folder is a build output of `stateless-squad-game-publisher`; do not edit it by hand.

- [Slingstar](https://www.statelesssquad.com/slingstar/): Tap. Sling. Shine.
- [Snike](https://www.statelesssquad.com/snike/): Eat the light. Grow legs. Bite the dark.
- [Promptstorm](https://www.statelesssquad.com/promptstorm/): Vibe code. Dodge the hype.
- [Aurolith](https://www.statelesssquad.com/aurolith/): Slice light. Climb to stars.
- [Word Garden](https://www.statelesssquad.com/word-garden/): Hear it. Find it. Grow it.
- [StateLess-Cube](https://www.statelesssquad.com/stateless-cube/): Merge. Combo. Climb.
- [StateLess Merge](https://statelesssquad.github.io/sample-app-skeleton-public/): Merge. Combo. Climb.
- [Pairs](https://statelesssquad.github.io/sample-app-skeleton-public/): Remember where they are.
- [Wordy](https://statelesssquad.github.io/sample-app-skeleton-public/): One word a day. Six tries.
- [Hopper](https://statelesssquad.github.io/sample-app-skeleton-public/): One button. Endless sky.
- [Drift](https://statelesssquad.github.io/sample-app-skeleton-public/): Collect the light. Outrun the dark.
- [Catch](https://statelesssquad.github.io/sample-app-skeleton-public/): Catch the fruit. Dodge the bombs.
- [Lumen](https://statelesssquad.github.io/sample-app-skeleton-public/): Light every tile.
